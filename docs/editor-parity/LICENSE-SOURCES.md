# glTF Scene Editor Source And Asset Provenance

This file is the authoritative provenance ledger for the MGIF glTF scene editor parity work. Every copied or adapted source file, generated asset, third-party fixture, icon, screenshot, and test corpus entry must be recorded before it enters a release candidate.

## Policy

- `concept-only`: behavior or architecture was studied, but no source text or asset bytes were copied.
- `adapted`: implementation was derived from upstream source and must retain the upstream license and notices required for redistribution.
- `copied`: upstream bytes are present verbatim and require exact file-level provenance.
- `original`: created for MGIF without external source bytes.
- Reference screenshots and runtime traces are evidence, not redistributable UI assets. They stay in ignored validation output and must still record executable provenance and hashes.
- New provenance entries must include repository or download URL, immutable revision/hash, upstream path, license, MGIF destination, classification, and any notice action.
- Source with an unknown or incompatible license is not admitted. Record its acquisition recipe and hash instead of committing it.
- The repository root remains unlicensed and rights-reserved for distribution until the project owner explicitly selects a root license. This does not block internal P1 engineering, but it blocks F42, R24, and every release/distribution PASS claim.
- New editor implementation is original clean-room behavior work unless a ledger row explicitly classifies it as copied or adapted. No upstream Apache source text is copied by default, and all existing third-party notices must be preserved.
